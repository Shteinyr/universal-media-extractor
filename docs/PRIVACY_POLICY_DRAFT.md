# Privacy Policy Draft

Date: 2026-08-05

Status: product draft, not legal advice. Review before public launch.

## Local-First Principle

Universal Media Extractor is designed to process media locally on the user's computer. The current MVP does not require uploading media files, transcripts, cookies, passwords, or API keys to a cloud service.

## Data Processed Locally

The app may process:

- URLs entered by the user;
- local files selected by the user;
- media metadata;
- downloaded files;
- transcripts generated by local Whisper;
- local logs and diagnostics;
- local output folder paths.

## Data Stored Locally

The app may save:

- downloaded media outputs;
- selected transcript files;
- metadata JSON files;
- local logs;
- redacted proof/diagnostic artifacts;
- output indexes/history once implemented.

## Credentials And Cookies

The public commercial product should not store passwords, cookies, tokens, or DRM keys. Internal/experimental browser-session features must not copy secrets into output folders or diagnostics.

## Network Access

The app may access source websites when the user analyzes or downloads a URL. It may also later check for app or media-engine updates if that feature is implemented. The current product should not send source media to third-party AI services by default.

## Diagnostics

Future diagnostics bundles must be redacted by default and must not include cookies, tokens, full private URLs, transcripts, or sensitive local paths unless the user explicitly chooses to include them.

## User Control

Users control what URLs and files they provide, where outputs are saved, and when files are deleted.
