# Legal-Safe Product Copy

Date: 2026-08-05

## Safe Short Description

Universal Media Extractor is a local media downloader, organizer, and transcriber for macOS and Windows. It helps users save accessible media and transcripts into clean local folders without uploading source files to a cloud service.

## Safe Landing Headline Options

- Local media saving, organized.
- Save accessible media and transcripts on your computer.
- A local-first downloader and transcript workspace.

## Safe Subheadline

Analyze a media link or local file, choose a clear output preset, save it locally, and optionally create a transcript with local Whisper.

## Safe Feature Bullets

- Analyze supported media links before downloading.
- Save audio, video, subtitles, or transcripts into organized folders.
- Transcribe local or downloaded media with local Whisper.
- Keep processing on your computer; no media upload is required.
- Use clean presets instead of technical format lists.
- Keep outputs easy to find, copy, and archive.

## Required Limitation Copy

Use Universal Media Extractor only with media you own, created, or have permission to download and process. Source support is best-effort and may change when platforms change. The app does not bypass DRM, CAPTCHA, paywalls, login restrictions, or access controls.

## Privacy Copy

Universal Media Extractor is designed as a local-first app. Media processing runs on your computer. The app should not upload source media, transcripts, cookies, passwords, or API keys to a cloud service.

## Words And Claims To Avoid

Avoid:

- downloads everything;
- works with every website;
- bypasses restrictions;
- download any paid course;
- guaranteed platform support;
- invisible login extraction;
- cloud AI summary as a core promise before it exists.

Use instead:

- supported sources;
- best-effort extraction;
- accessible media;
- user-authorized content;
- local processing;
- no cloud upload required.

## Error Copy Direction

Prefer user-facing categories over raw CLI errors:

- Source unavailable.
- Login required.
- DRM-protected content is not supported.
- Format unavailable.
- Network interrupted.
- Disk or permission problem.
- Media engine update may be required.

Technical details can remain available in collapsible diagnostics, but public UI should lead with plain language.

## Website Copy Boundary

The public site can mention:

- YouTube and other supported public media sources as examples only if phrased as best-effort;
- local files;
- audio/video/subtitles/transcripts;
- macOS and Windows roadmap;
- privacy/local-first workflow.

The public site should not advertise Udemy course export while it remains internal/experimental.
