## Value Props

- Local-first processing: source files and transcripts stay on the user's machine.
- Clean outputs: files are saved into predictable folders with readable names.
- Simple presets: video, audio, subtitles, and transcript choices without raw technical format lists.
- Useful for creators, editors, students, researchers, and knowledge workers.
- Best-effort support through proven local engines: `yt-dlp`, `ffmpeg`, and Whisper.

## Feature Sections

### Analyze Before Saving

Paste a supported media link or choose a local file. The app inspects available outputs before taking action.

### Download Organized Outputs

Save video, audio, or subtitles into local folders with safe names, duplicate handling, and reveal-in-Finder/Explorer behavior.

### Transcribe Locally

Create a transcript with local Whisper and save exactly the format you choose: TXT, Markdown, or JSON.

### Keep Control

No cloud media upload is required. You choose the source, output folder, format, and whether to process the result.

## Required Limitation Copy

Use Universal Media Extractor only with media you own, created, or have permission to download and process. Source support is best-effort and may change when platforms change. The app does not bypass DRM, CAPTCHA, paywalls, login restrictions, regional restrictions, or access controls.
