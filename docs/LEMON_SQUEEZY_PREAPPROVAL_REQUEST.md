## Subject

Pre-approval request for local desktop software: Universal Media Extractor

## Product Summary

Universal Media Extractor is local desktop software for macOS and Windows. It helps users analyze accessible media links or local audio/video files, choose simple output presets, save files into organized local folders, and optionally create local transcripts with Whisper.

The product is sold as desktop software, not as a hosted media extraction service. Source media and transcripts are processed locally on the user's computer and are not uploaded to our servers by default.

## Intended Customer

- Individual creators, researchers, students, editors, and knowledge workers.
- Small teams that need organized local media files and transcripts.
- Users who have the right to download, save, or process the media they use with the app.

The product will be fulfilled as downloadable desktop software for macOS and Windows.

Planned release artifacts:

- signed/notarized macOS app and DMG when Apple Developer Program access is ready;
- signed Windows installer later;
- license key delivered after purchase;
- no physical goods.

## Important Safety Boundary

Universal Media Extractor:

- does not bypass DRM;
- does not bypass CAPTCHA;
- does not bypass paywalls;
- does not bypass login restrictions or platform access controls;
- does not host, sell, or distribute third-party media;
- does not provide cloud extraction or file-sharing;
- does not store user passwords, cookies, or tokens;
- does not advertise guaranteed support for every website;
- requires users to confirm they have rights to download/process media.

Source support is best-effort and may change when third-party platforms change.

## Internal / Experimental Features

Udemy Course Mode exists only as an internal/experimental local workflow for user-owned or user-authorized course access. It is hidden from public commercial builds and will not be advertised in public product copy unless separately reviewed and approved.
