# Beta Onboarding Copy

Purpose: first-run/beta copy for Universal Media Extractor.

## First-Run Screen

Title:

```text
Welcome to Universal Media Extractor
```

Body:

```text
This app helps you save accessible media and transcripts into organized local folders. Processing runs on your computer; source media is not uploaded to a cloud service by default.
```

## Before First Download

Title:

```text
Use media you have rights to process
```

Body:

```text
Only download or transcribe media you own, created, or have permission to use. The app does not decide whether a source is legally allowed for your situation.
```

## Source Limitations

Title:

```text
Source support is best-effort
```

Body:

```text
Some sources may fail because platforms change, require login, restrict regions, remove formats, or protect content. The app does not bypass DRM, CAPTCHA, paywalls, login restrictions, or access controls.
```

## Local Privacy

Title:

```text
Local-first by design
```

Body:

```text
Downloads, transcripts, logs, and outputs are saved on your computer. Diagnostics should be redacted before sharing and should not include cookies, tokens, transcripts, or private paths.
```

## Beta Expectations

Title:

```text
Beta means careful testing
```

Body:

```text
Start with one small file or link. Check the output folder before running larger jobs. If something fails, keep the diagnostic error and try a smaller or clearer source.
```

## Checklist Copy

- I understand source support is best-effort.
- I will use the app only with media I have rights to download or process.
- I understand DRM, CAPTCHA, paywalls, and access controls are not bypassed.
- I understand processing is local and outputs are stored on this computer.

## UI Placement

Recommended placements:

- First app launch modal or onboarding screen.
- Website beta section.
- Download page before installer link.
- In-app legal/safety note before first download.

Do not block every normal workflow with repeated onboarding once the user has acknowledged it.
