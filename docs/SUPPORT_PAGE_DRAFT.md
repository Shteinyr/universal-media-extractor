# Support Page Draft

## Support Promise

Universal Media Extractor is a local-first desktop app. Support focuses on installation, local app behavior, diagnostics, output folders, and best-effort media engine compatibility.

## Before Contacting Support

Try:

1. Restart the app.
2. Test with one small source.
3. Confirm enough disk space.
4. Confirm the source is accessible in your browser.
5. Check whether the error mentions DRM, login, region, unavailable source, or media engine update.

## Safe Diagnostic Info

Safe to share:

- app version;
- macOS/Windows version;
- normalized error category;
- redacted diagnostics bundle;
- whether the issue happened during analyze, download, transcription, or output reveal.

Do not share:

- passwords;
- cookies;
- tokens;
- full private URLs;
- transcripts with sensitive content;
- local file paths that reveal private information.

## Unsupported Requests

Support cannot help with:

- DRM bypass;
- CAPTCHA bypass;
- paywall bypass;
- login restriction bypass;
- downloading content without permission;
- extracting cookies, tokens, or DRM keys.
